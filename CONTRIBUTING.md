# Contributing to LLMenuBar

Thank you for your interest in contributing to LLMenuBar.

Please report bugs or suggest improvements by opening a GitHub Issue.

Pull requests are not accepted.

## Bug reports: *use GitHub Issues*

Please file a bug report as a GitHub Issue. Before filing, search existing Issues to avoid duplicates.

A useful bug report includes:

- macOS version
- LLMenuBar version, shown in the About window
- Splash inference engine version, shown in Settings > General > Engine
- Steps to reproduce
- Expected behavior
- Actual behavior
- How often this happens, for example: always, sometimes, or only after restart
- Relevant log output from the problematic session, plus the `exec:`, `cwd:`, `env:`, and `argv:` header from the start of that session

You can open the log from the menu or from Settings > Diagnostics. API keys and secret-looking environment variables such as `HF_TOKEN` are shown as `REDACTED`. Please check the log for any remaining secrets before posting it.

## Feature requests: *use GitHub Issues*

Please open a GitHub Issue describing the problem you are trying to solve.

A useful feature request includes:

- What you are trying to do
- What is currently in the way
- How often you encounter the problem
- Any workaround you currently use

The ultimate shape of any fix is up to the maintainer.
